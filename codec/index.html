What's in the Toolbox

🔤

Base64

Encode and decode Base64 with URL-safe and padding toggles. Auto-detects alphabet and surfaces double-encoded strings.

🔗

URL Encode / Decode

Percent-encode query, path, and form components. Auto-detects and unwraps double-encoded strings.

#

Hex

Convert text to and from hex with uppercase, lowercase, and 0x prefix options.

🔐

Hash & HMAC

MD5, SHA-1, SHA-256, SHA-384, SHA-512, and HMAC with a user-supplied key — all computed locally.

📄

File Hash

Drag a file in to compute its SHA-256 (and other digests) without uploading anything.

{ }

JSON Formatter

Pretty-print, minify, and validate JSON. Spot syntax errors instantly with line-precise highlighting.

Aa

Case Converter

Flip between camelCase, snake_case, kebab-case, CONST_CASE, PascalCase, and Title Case.

🔍

String Inspector

Count characters, bytes, lines, and words, with a quick entropy estimate for inspecting payloads.

.*

Regex Tester

Live regex testing with capture groups, named groups, flags, and per-match highlighting.

🪪

JWT Decoder

Decode JWT header and payload, see the signature status, and watch exp count down in real time.

cURL

cURL Builder

Compose a request with method, headers, and body, then copy a clean, ready-to-paste cURL command.

🆔

UUID Generator

Generate UUID v4 (and v7 in a future update) — individually or in bulk, ready to copy.

🔑

Password Generator

Cryptographically strong passwords with configurable length, charset, and live entropy readout.

⏱️

Timestamp

Convert between Unix epoch and human-readable time, with ISO-8601 and custom timezone support.

📅
New

Cron "Next Five"

Type a cron expression and see the next five fire dates — perfect for sanity-checking scheduled jobs.

🖼️

Image ↔ Base64

Drag an image in to get its Base64 string, or paste a Base64 string to preview the decoded image.
